# 🛒 Virtual Store System

Um sistema de backend robusto que simula o ecossistema de uma loja virtual. O foco deste projeto é a implementação de lógica de negócios complexa, como gestão de inventário, processamento de pedidos e persistência de dados.

---

### 🛠️ Tecnologias e Arquitetura

* **Python**: Linguagem principal utilizada para a lógica procedural e orientada a objetos.
* **Estruturas de Dados Dinâmicas**: Utilização de dicionários e listas para otimizar a busca e manipulação de produtos.
* **Módulos de Gestão**: Separação de responsabilidades entre catálogo de produtos, carrinho de compras e sistema de checkout.
* **Validação de Dados**: Tratamento de exceções para garantir que operações de stock e preços sejam processadas corretamente.

---

### ✨ Funcionalidades Principais

* **Gestão de Inventário**: Cadastro, atualização e consulta de stock em tempo real.
* **Carrinho de Compras Inteligente**: Cálculo automático de totais, sub-totais e aplicação de regras de negócio.
* **Simulação de Checkout**: Fluxo completo desde a escolha do produto até a finalização do pedido.
* **Interface de Linha de Comando (CLI)**: Navegação intuitiva para simular a experiência do utilizador e do administrador.
